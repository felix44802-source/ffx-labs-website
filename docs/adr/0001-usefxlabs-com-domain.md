# Use usefxlabs.com instead of fxlabs.com

`fxlabs.com`, `fxlabs.ai`, `getfxlabs.com`, and `tryfxlabs.com` are all already registered by third parties (confirmed via RDAP lookups). Renaming the brand to secure a clean match was considered and rejected — `Fx Labs` was already settled on. We initially considered `fxlabs.io`, but decided a `.com` carries more trust with the target audience of small business owners than a `.io`, so we registered `usefxlabs.com` instead — a clean, available `.com` that reads as a direct call-to-action.
